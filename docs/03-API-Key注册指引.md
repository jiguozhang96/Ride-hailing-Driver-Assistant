# 高德地图 API Key 注册指引

> 本产品已预置你的高德配置，**打开即用**。此文档说明 key 类型、安全注意事项与更换方法。

## 一、正确的 key 类型（重要）

本产品使用高德 **JS API 2.0**（Web端），因此 key 必须申请为：

- **服务平台：「Web端（JS API）」** ← 正确
- ❌ 不要选「Web服务」——那是 REST 接口 key，会报 `USERKEY_PLAT_NOMATCH`（错误码 10009）。

配套还需要一个 **安全密钥 jscode**（申请 key 时高德会提示创建）。

> 已实测：你的 key + jscode 在 JS API 2.0 下可正常调用「地图 / 驾车规划 / POI 搜索 / 天气 / 地理编码」全部能力。

## 二、注册步骤（若需重新申请）

1. 访问 https://lbs.amap.com 注册并完成**个人开发者实名认证**（身份证 + 手机号）。
2. 控制台 → 应用管理 → 创建应用。
3. 应用下「添加 Key」：**服务平台选「Web端（JS API）」**；同时创建**安全密钥 jscode**。
4. 复制 Key 和 jscode，在本产品「我的」页填入并保存。

## 三、⚠️ 安全须知（必读）

纯前端应用（H5）的 key 会暴露在网页源码中，任何人查看源码都能看到。**必须做域名白名单**：

1. 高德控制台 → 应用管理 → 找到该 key → 设置 → **「域名白名单」**。
2. 填入你自己的域名（例如部署后的 `xxx.app.workbuddy.link` 或你的正式域名）。
3. 白名单之外的域名无法使用该 key，即使 key 泄露也不会被盗刷。

> 若 key 已泄露，可在控制台「删除并重建」，再更新到本产品即可。

## 四、更换 / 清空 key

打开 H5 →「我的」→ 修改 Key 与 jscode →「保存配置」。留空保存即恢复为「无 key 离线模式」（内置 SVG 示意图仍可用）。

## 五、费用

个人开发者有免费月度配额（JS API 按调用计费，个人额度对「司机单人自用」完全够用，通常零费用）。

# 网约车跑单规划助手 —— 用户使用手册

## 一、如何打开

**方式 A：本地预览（开发/自用）**
```bash
cd app
python -m http.server 8756
# 浏览器访问 http://127.0.0.1:8756/index.html
```
Windows 可直接双击项目根目录下的 `启动服务.bat`。

**方式 B：手机访问（推荐）**
将 `app/` 目录部署到任意静态托管（或使用 CloudStudio 沙箱部署），用手机浏览器打开生成的网址即可。

## 二、五步上手

1. **填档案**：首页填写城市、住宿地址、车辆类型、车牌类型、续航、出车/收车时间，勾选是否接跨城单/是否大周，选择今日天气。
2. **生成**：点「生成跑单规划」。
3. **看日规划**：查看当天每个时段的推荐点位、热力星级、策略建议、里程。
4. **看示意图**：底部「示意图」查看路线连线（颜色越红热力越高）。
5. **导出/导航**：复制文字版发给同行，导出 CSV 存档，点「导航」跳转高德导航。

## 三、各视图说明

| 视图 | 作用 |
|---|---|
| 首页 | 填写/修改司机档案，生成规划 |
| 日规划 | 当天分时段跑单路线表 |
| 周规划 | 未来 7 天节奏（含单双休差异） |
| 示意图 | 路线可视化（离线 SVG / 高德在线） |
| 我的 | 配置高德 key、导出导入数据、查看历史 |

## 四、关键概念

- **热力星级**：★越多代表该时段该点位打车需求越高（爆单区=★★★★★）。
- **运营里程 vs 空驶**：运营里程 = 载客+等客行驶；空驶 = 点位间转移不载客。规划会尽量降低空驶。
- **续航约束**：累计接近续航 80% 时，规划自动插入充电/加油停留（新能源插充电，油车插加油）。
- **大周**：互联网公司「大小周」中上班的周六，当天漕河泾/张江等园区加班打车单较多。
- **反扎堆**：规划会避免长时间蹲守同一热点，按时段轮换商圈，降低同行扎堆竞争。

## 五、数据与隐私

- 所有数据（档案、历史、key）仅保存在**本机浏览器 localStorage**，**不会上传任何服务器**。
- 清除浏览器数据会导致档案丢失，可提前在「我的 → 导出数据」备份 JSON。

## 三、多端部署方案

### 方案 1：移动端网页（H5，已实现）

- 响应式设计，手机浏览器直接访问。
- 部署：任意静态托管（CloudStudio/OSS/对象存储），或 `node server.js`（隐藏 REST key）。
- 可扩展 PWA（加 manifest + service worker 实现离线缓存）。

### 方案 2：Docker（含飞牛 fnOS NAS，已提供）

```bash
docker compose up -d          # 云服务器
# 飞牛 fnOS：Docker 应用 → Compose → 新建 → 粘贴 docker-compose.yml → 启动
# 访问 http://<NAS-IP>:3000
```

- `Dockerfile` + `docker-compose.yml` 已提供。
- REST 类 key（和风/高德 Web服务）只存服务端环境变量，前端不可见。

### 方案 3：微信小程序（迁移指引）

- 本工具为纯前端 H5，可用 **uni-app / Taro** 迁移为小程序（一套代码编译多端）。
- 关键适配点：
  1. `localStorage` → `uni.setStorageSync`
  2. `fetch` → `uni.request`
  3. `navigator.geolocation` → `uni.getLocation`（需申请小程序定位权限）
  4. 高德 JS API → 微信内置 map 组件 + 高德微信小程序 SDK
  5. 域名白名单：小程序后台配置 request 合法域名（和风/高德 REST）
- 核心算法引擎（engine/*.js）为纯逻辑，可直接复用。

### 方案 4：桌面本地程序（Electron，已落地 ✅）

- 工程位于 `electron/`，已提供 `main.js`（主进程）+ `package.json` + `config.json`（密钥配置）。
- 原理：主进程启动内嵌 `proxy-server.js` 服务（REST key 只存本机环境变量/`config.json`），窗口加载该服务，前端零改动。
- 使用：

```bash
cd electron
npm install              # 首次安装依赖
npm start                # 本地启动（开发）
npm run build:win        # 打包 Windows 安装包（portable 绿色版 + NSIS 安装版，输出到 electron/dist/）
```

- 双击 `electron/启动桌面版.bat` 可一键启动。
- 密钥优先级：环境变量 > `electron/config.json`（本地文件，不随源码外发）。

# 07 · 商圈数据更新维护指南

商圈点位库（`app/js/engine/poi-db.js`）由高德 Web服务 POI 搜索自动生成，支持一键更新维护。

## 当前数据规模

- **12 城市**：上海/北京/杭州/苏州/深圳/长沙/广州/成都/武汉/南京/西安/重庆
- **已网格化（7 城）**：
  - 上海 891 点（2.5km 间距）
  - 北京 421 / 杭州 234 / 苏州 208 / 深圳 201 / 长沙 181 / 广州 168（3km 间距）
- **待网格化（5 城，暂用分类搜索数据）**：成都 57 / 武汉 55 / 南京 53 / 西安 45 / 重庆 57

> ⚠️ 成都/武汉/南京/西安/重庆因**高德个人 key 日配额（5000 次/天）用尽**，本次未完成网格采集，已回退为分类搜索数据。配额次日自动恢复后，跑 `python scripts/grid_poi.py --city 成都`（依次替换 5 城）即可补全。

## 数据采集方式

### 上海：网格矩阵采集（`scripts/grid_poi.py`）

把上海全域（外环内 + 主要新城）划分成 **35×31 ≈ 1020 个 2.5km 网格**，每格用高德 `around` 周边搜索分三类采集：

| 类别 | 高德 typecode | zone 类型 | 采样密度 | 热度权重 w |
|---|---|---|---|---|
| 商场 | 060100 | shop | 每格 TOP1 | 1.25 |
| 写字楼 | 120201 | biz | 每格 TOP1 | 1.15 |
| 住宅小区 | 120302 | home | 隔格 TOP1 | 1.05 |

- **热度权重 w**：按搜索排名赋值，区分大商圈与小商圈，热力模型 `heatScore` 会乘以 `zone.w`。
- **跨城市过滤**：按高德返回的 `cityname` 过滤（西边界易搜到昆山/苏州，已内置过滤）。
- 特殊点位（机场/火车站/酒吧/大学/美食街/景区）从分类搜索保留。

### 其余城市：网格矩阵采集（`scripts/grid_poi.py`，多城市）

同一脚本支持 12 城网格采集（每城已配置主城区网格范围 + 城市名过滤）。

## 一键更新

```bash
# 全量网格采集 12 城（约 20 分钟，5500+ 次 API 调用，注意日配额）
python scripts/grid_poi.py

# 只采集单个城市
python scripts/grid_poi.py --city 成都

# 跳过某城市（如已采过）
python scripts/grid_poi.py --skip 上海

# 清理跨城市误采点（网格边界 regeo 验证）
python scripts/fix_boundary.py

# 分类搜索兜底（配额不足时的备选，每城约 90 次调用）
python scripts/update_poi.py --city 北京
```

- key 从环境变量 `AMAP_WS_KEY` 读取，或改脚本顶部 `KEY` 默认值。
- **⚠️ 配额注意**：高德个人 key 日配额 5000 次/天。全量 12 城网格化约 5500+ 次调用，**单日会超配额**。建议分批（每天 3-4 城）或申请企业 key 提额。
- 更新后 `app/js/engine/poi-db.js` 自动重写；**同时手动同步到小程序**：

```bash
cp app/js/engine/poi-db.js miniprogram/src/utils/engine/poi-db.js
```

## 维护建议

1. **每月重跑一次**：新开业/关闭的商场、新开通的高铁站会自动更新（高德 POI 持续维护）。
2. **高德配额**：上海网格采集约 2550 次/次，其余城市约 90 次/城；低于免费额度（个人 5000 次/天，可申请提额）。
3. **限速**：脚本内置 0.15-0.18s 间隔，避免触发 QPS 限频。
4. **扩展网格到其他城市**：`grid_poi.py` 里复制 `SH_GRID` 改为目标城市经纬度范围 + 改 `CITY_FILTER` 城市名即可。

## 常见问题

- **数据全是郊区无名商场**：高德 `sortrule=weight` 按热度排序，一般返回知名商圈；若异常，检查 key 是否被限频。
- **跨城市误采**：网格边界（如上海西边界）会搜到昆山/苏州的 POI，`grid_poi.py` 已按 `cityname` 过滤；历史数据可用 `fix_boundary.py` 清理。
- **想恢复旧版**：更新前建议 `cp poi-db.js poi-db.bak.js` 备份。

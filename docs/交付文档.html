01 · 调研报告

一、结论摘要

1. 产品定位安全。面向司机自用的行程规划工具不触碰合规红线；红线是「自动抢单 / 虚拟定位 / 接入平台私有接口」，本产品三者均不涉及。高置信

2. 技术路线可行。纯前端 H5 + 高德 API + 本地存储即可完整交付，无需后端服务器；高德个人开发者即可申请（月配额制），无企业资质门槛。高置信

3. 核心差异化。竞品已有"热力图/听单推荐"，但存在热力图滞后、司机扎堆两大痛点；本产品差异化是「提前 30-60 分钟供需缺口预判 + 反扎堆路线轮换」。中置信

4. 数据短板已规避。真实订单热力不对个人开放，采用「规则引擎 + 公开 POI/班次常识」构建热力模型，可调参、可接入真实数据源。高置信

02 · 产品设计方案

一、产品概述

一句话定位：帮司机在出车前快速生成「今天去哪跑、几点去、顺不顺路、要不要充电」的日度/周度路线规划。

痛点现状解法
不知道去哪等单凭经验/跟风扎堆按时段热力推荐 + 反扎堆轮换
新能源怕没电自己算续航续航约束 + 充电停留规划
限行被罚记不住规则按车牌自动判定 + 规避
吃饭没着落随机找地方司机餐饮带补给节点
不懂单双休周一/周六乱跑周度规划体现大小周

二、用户旅程

司机打开 H5 → 填档案(城市/住宿/车型/车牌/续航/出车收车/跨城/大周/天气)
→ 点「生成跑单规划」→ 查看日度规划表(时间→点位→热力→策略→里程)
→ 查看路径示意图 → 查看周度规划 → 复制/导出CSV/跳转导航 → 数据自动保存在本机

4.2 热力公式

热力分(zone, 星期, 小时, 天气) = 基础模板[类型][小时] × 星期修正 × 天气系数

天气系数：晴 1.0 / 多云 1.0 / 小雨 1.25 / 暴雨 1.5 / 雪 1.4 / 极端 0.6。

五、日度规划算法

输入：档案(车型/车牌/续航/出车收车/跨城/大周) + 日期 + 天气
输出：分段跑单时间表 + 总里程 + 摘要

1. 按 2h 把出车-收车时段切成时间窗
2. 每窗打分：热力分 − 空驶距离×0.35 + 连续性奖励/惩罚 + 跨城枢纽加成
3. 贪心选最高分点位；连续停留≥2窗扣 1.8 分（反扎堆）
4. 运营里程 = 时长 × 18km/h；累计接近 80% 续航 → 插入充电/加油
5. 饭点(11-13/17-19) → 最近司机餐饮带
6. 收车 → 回住宿地路径

高德集成采用 JS API 2.0 插件体系（key 类型为「Web端 JS API」+ 安全密钥 jscode），而非 REST 接口。

03 · 高德地图 API Key 注册指引

本产品已预置高德配置，打开即用。此文档说明 key 类型、安全注意事项与更换方法。

一、正确的 key 类型（重要）

本产品使用高德 JS API 2.0（Web端），key 必须申请为 「Web端（JS API）」；❌ 不要选「Web服务」（会报 USERKEY_PLAT_NOMATCH 10009）。配套需创建安全密钥 jscode。

二、注册步骤（若需重新申请）

1. 访问 https://lbs.amap.com 注册账号，完成个人开发者实名认证（身份证+手机号）。

2. 控制台 → 应用管理 → 创建新应用（名称任意）。

3. 应用下「添加 Key」：服务平台选「Web端（JS API）」；同时创建安全密钥 jscode。

4. 复制 Key 和 jscode，在本产品「我的」页填入并保存。

三、⚠️ 安全须知（必读）

纯前端 H5 的 key 会暴露在源码中。必须设置域名白名单：高德控制台 → 应用管理 → key 设置 →「域名白名单」→ 填入你的域名。白名单外无法使用该 key，即使泄露也不会被盗刷。

四、费用说明

个人开发者有免费月度配额，对「司机单人自用」场景完全够用，通常零费用。

四、关键概念

热力星级：★越多需求越高（爆单区=★★★★★）。
运营里程 vs 空驶：运营=载客+等客；空驶=点位间转移不载客，规划尽量降低空驶。
续航约束：累计接近 80% 续航自动插入充电/加油。
大周：互联网「大小周」中上班的周六，漕河泾/张江加班单较多。
反扎堆：避免长时间蹲守同一热点，按时段轮换商圈。

五、数据与隐私

所有数据仅保存在本机浏览器 localStorage，不上传任何服务器。可提前在「我的 → 导出数据」备份。
